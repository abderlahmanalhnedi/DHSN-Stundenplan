# Security / Sicherheit

This is an **unofficial** Home Assistant integration for **Duale Hochschule Sachsen (DHSN)**.

**Never upload sensitive material** to public GitHub issues: login details, browser HAR recordings, session tokens, cookies, HTTP authorization headers, private timetables or other personal data.

For non-sensitive bug reports, use [GitHub Issues](https://github.com/abderlahmanalhnedi/DHSN-Stundenplan/issues). For security reports involving secrets, use a private maintainer contact channel if one is available on the maintainer's GitHub profile; do not publish exploit details.

The integration is read-only and does not request DHSN login credentials. Access restrictions must not be bypassed. No security support SLA or formal bug bounty program is offered.

**Deutsch:** Sicherheits- und Datenschutzfragen nur ohne geheime oder personenbezogene Informationen in öffentlichen Issues melden. HAR-Dateien, Cookies, Tokens und Hochschul-Zugangsdaten dürfen nicht veröffentlicht werden. Für vertrauliche Sicherheitsmeldungen nach Möglichkeit einen privaten Kanal zum Projektbetreuer verwenden.
