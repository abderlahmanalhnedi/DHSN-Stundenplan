## English

This is an **independent, unofficial** open-source calendar project intended for **Duale Hochschule Sachsen (DHSN)**. It is **not** commissioned, approved, reviewed, affiliated with or supported by DHSN, Campus Dual, or the timetable service operator.

University names are used solely to identify the intended use. No official university logo or proprietary timetable dataset is distributed.

The integration issues direct, read-only requests for a user-selected group from the user's own Home Assistant installation. It does not bypass login requirements. **An accessible endpoint does not itself authorize automated data access.** Users must respect service rules and third-party rights. In normal operation the integration checks approximately once per hour per configured group; mass collection and group enumeration are not intended uses.

If an operator or rights holder objects or restricts access, automated requests should be stopped immediately. Concerns can be raised through [GitHub Issues](https://github.com/abderlahmanalhnedi/DHSN-Stundenplan/issues) without posting sensitive information; see [SECURITY.md](SECURITY.md).
